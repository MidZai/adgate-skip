AdGate Skip

Le lecteur impose cinq pubs avant de démarrer, chacune ouvrant un onglet pour faire avancer un compteur de 20 %. Ce script remplit le compteur tout seul, sans ouvrir la moindre pub.

1

Installer le gestionnaire de scripts

Violentmonkey est gratuit et open source, c'est lui qui exécute le script. Si tu as déjà Violentmonkey ou Tampermonkey, passe à l'étape suivante.

Installer Violentmonkey
2

Autoriser les scripts utilisateur

Chrome bloque les gestionnaires de scripts tant que cette option n'est pas cochée, et sans rien signaler : le script apparaît installé et actif, mais ne s'exécute jamais. Impossible de l'activer à ta place, c'est exactement ce que cette protection empêche.

Colle cette adresse dans la barre du navigateur, puis active Autoriser les scripts utilisateur :

chrome://extensions/?id=jinjaccalgkegednnccohejagnlnfdag

Ensuite redémarre Chrome. Violentmonkey ne réenregistre ses scripts qu'au démarrage, recharger la page ne suffit pas.
3

Installer le script

Violentmonkey ouvre un écran de confirmation, il reste à valider. C'est un écran de consentement : aucune page web ne peut le valider à ta place. Les mises à jour, elles, se feront ensuite toutes seules.

Installer AdGate Skip
Le clic affiche du code au lieu d'une confirmation ? L'étape 1 n'est pas faite.
4

Ouvrir un épisode

Le badge passe par « Vérification Cloudflare… » quelques secondes, puis le compteur monte à 100 % et la lecture démarre. Si ça coince, un bouton Skip pubs attend en bas à droite, ou Ctrl + Shift + S.

Rien ne se passe malgré tout

Sur Chrome, c'est l'étape 2 neuf fois sur dix, et le redémarrage est la partie qu'on oublie. Le témoin fiable est le bouton Skip pubs en bas à droite : il apparaît dès que le script s'exécute, même si la suite échoue. Pas de bouton = le script n'est jamais injecté, et le problème vient du gestionnaire.

Sinon, voici la version sans extension. Fais apparaître la barre de favoris (Ctrl+Shift+B) et glisse ce lien dedans. Sur une page d'épisode, un clic dessus lance le skip.

↧ AdGate Skip

Aucune extension, aucun réglage, tous navigateurs. En contrepartie il faut cliquer le favori à chaque épisode.

Comment ça marche

Le lecteur est un composant Livewire dont l'état (currentStep, total_steps) vit côté serveur. Le bouton « Continuer » est un lien wire:click="incrementSteps" doublé d'un window.open vers la régie : la pub n'est jamais une condition, seulement un effet de bord. Le contrôle des « 3 secondes minimum » de la variante openAdTab() est lui aussi purement côté client.

Le script appelle donc incrementSteps cinq fois et neutralise window.open au passage, ce qui supprime les popunders. Aucune requête n'atteint les régies.

Le compteur n'est pas le dernier verrou : à 100 % le serveur attend encore un jeton Cloudflare Turnstile avant de livrer la vidéo. Le script l'attend donc avant d'incrémenter, sinon le re-render détruit le widget et le player n'arrive jamais.

Sans gestionnaire de scripts

Une extension Manifest V3 est fournie dans le dépôt, sous extension/, chargeable via chrome://extensions en mode développeur ou via about:debugging sur Firefox 128+.

À savoir : une extension non signée ne peut pas s'installer automatiquement, les navigateurs le bloquent volontairement, et Firefox décharge les extensions temporaires à chaque redémarrage.
