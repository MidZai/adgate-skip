AdGate Skip

Le lecteur impose cinq pubs avant de démarrer, chacune ouvrant un onglet pour faire avancer un compteur de 20 %. Ce script remplit le compteur tout seul, sans ouvrir la moindre pub.

1

Installer le gestionnaire de scripts

Violentmonkey est gratuit, open source, et sert à exécuter le script. Si tu as déjà Violentmonkey ou Tampermonkey, passe directement à l'étape 2.

Installer Violentmonkey
2

Autoriser les scripts utilisateur

Chrome bloque les gestionnaires de scripts tant que cette option n'est pas cochée, sans le signaler : le script s'affiche comme installé et actif, mais ne s'exécute jamais. Impossible de l'activer à ta place, Chrome l'interdit justement pour empêcher qu'une page le fasse.

Colle cette adresse dans la barre du navigateur, puis active Autoriser les scripts utilisateur :

chrome://extensions/?id=jinjaccalgkegednnccohejagnlnfdag

Ensuite redémarre Chrome. Violentmonkey ne réenregistre ses scripts qu'au démarrage : recharger la page ne suffit pas.
2

Installer le script

L'écran de confirmation du gestionnaire s'ouvre, il n'y a qu'à valider. Les mises à jour se feront ensuite toutes seules.

Installer AdGate Skip
Rien ne se passe au clic ? C'est que l'étape 1 n'est pas faite : le navigateur affiche alors le code source au lieu de l'écran d'installation.
3

Ouvrir un épisode

Le compteur monte à 100 % en deux secondes et la lecture démarre. Si ça coince, un bouton Skip pubs attend en bas à droite, ou Ctrl + Shift + S.

Le script est installé mais rien ne se passe

Sur Chrome, un gestionnaire de scripts en Manifest V3 n'injecte rien tant que l'option Autoriser les scripts utilisateur n'est pas activée dans chrome://extensions → Détails de Violentmonkey. Après l'avoir activée, il faut recharger l'extension (ou redémarrer Chrome), pas seulement la page : Violentmonkey ne réenregistre ses scripts qu'au démarrage.

Si ça résiste, voici la version sans extension. Fais apparaître la barre de favoris (Ctrl+Shift+B), puis glisse ce lien dedans. Sur une page d'épisode, un clic dessus lance le skip.

↧ AdGate Skip

Ça ne dépend d'aucune extension ni d'aucun réglage, et ça marche sur tous les navigateurs. En contrepartie il faut cliquer le favori à chaque épisode.

Comment ça marche

Le lecteur est un composant Livewire dont l'état (currentStep, total_steps) vit côté serveur. Le bouton « Continuer » est un lien wire:click="incrementSteps" doublé d'un window.open vers la régie : la pub n'est jamais une condition, seulement un effet de bord. Le contrôle des « 3 secondes minimum » de la variante openAdTab() est lui aussi purement côté client.

Le script appelle donc incrementSteps cinq fois d'affilée et neutralise window.open au passage, ce qui supprime aussi les popunders. Aucune requête n'est envoyée aux régies.

Sans gestionnaire de scripts

Une extension Manifest V3 est fournie dans le dépôt, sous extension/. Elle se charge via chrome://extensions en mode développeur, ou via about:debugging sur Firefox 128+.

À savoir : une extension non signée ne peut pas s'installer automatiquement, les navigateurs le bloquent volontairement. Et sur Firefox, une extension temporaire disparaît à chaque redémarrage. Le userscript reste nettement plus pratique au quotidien.

Si ça ne marche plus
  • Le site change de domaine régulièrement. Il faut alors mettre à jour les lignes @match du script.
  • Le compteur se bloque ? Rafraîchir la page le remet à zéro côté serveur, puis relancer avec le bouton.
  • La console du navigateur affiche chaque étape sous le préfixe [adgate].
